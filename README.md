# Daan's Games

Mijn zelfgebouwde browsergames, live op **https://daanbaard.github.io/games/**.

Elke push naar `main` zet de site automatisch online. Een game is een map met `index.html` + `game.json` (+ optioneel `thumb.png`); de overzichtspagina vult zichzelf.

Nieuwe versie uit een zip: `python3 scripts/publish_zip.py tumblerz_v1.3.zip` → commit → push.
